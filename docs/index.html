✨ What's Inside

🎨 Catppuccin Mocha

17 custom CSS mods with glassmorphism, animations, pill workspace buttons, glowing tabs. 3 theme variants (Mocha/Macchiato/Frappé).

🤖 Local AI Stack

9 Ollama models. Streaming chat in terminal (vc-ask), bookmark categorization, daily AI briefing. 100% offline-capable.

🎙️ Voice Control

OpenAI Whisper local transcription. Speak commands in Azerbaijani or English. ffmpeg + pipewire. Zero cloud dependency.

📊 Web Cockpit

FastAPI dashboard at localhost:8001. Live WebSocket metrics, AI chat, universal search, focus mode, snapshots.

🔍 Universal Search

vc-find searches across 390 bookmarks + history + 6 notes simultaneously. BM25 ranking, no embeddings needed.

🍅 Pomodoro Focus

vc-focus with KDE notifications, halfway alerts, statistics. Built-in distraction tracking and session log.

🔐 GPG Notes

ed25519 key, encrypt individual notes inline (PGP-armored), backup/restore commands. Vivaldi-aware.

📂 Workspace Snapshots

vc-snap saves/restores workspace state. Reads from Vivaldi history DB, opens all URLs in new window.

📡 RSS Reader

29 curated feeds across 6 categories. Hacker News, Phoronix, Krebs, Anthropic Research, Flutter dev.

🇦🇿 Azerbaijani UI

Full Vivaldi locale, 6 native AZ notes (cheatsheet, AI prompts, security), 18 proverbs in dashboard.

📅 Auto Reports

systemd timer for weekly bookmark health (Sun 03:00) + daily AI brief (08:00). PDF export with Catppuccin theme.

⌨️ Triple Control

54 keyboard shortcuts (F-key stream deck) + 15 mouse gestures (rocker) + voice. Three independent modes.

🛠️ Tech Stack
